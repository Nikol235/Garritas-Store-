# Garritas Store
Sistema distribuido de comercio electrónico y servicios para mascotas.

**Equipo:** Dreams Code

## Estructura del Proyecto
- infra/: Servidores centrales (Config Server, Eureka).
- services/: Microservicios de negocio (cada integrante crea el suyo aquí).
- obs/: Herramientas de observabilidad (Prometheus, Loki).
